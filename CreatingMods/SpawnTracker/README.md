# Spawn Tracker

Лёгкий клиентский мод для **Minecraft 1.21.1**, загрузчик **Fabric**.
Показывает в реальном времени, могут ли заспавниться фантомы, и что именно
мешает спавну прямо сейчас.

## Что показывает

Панель в левом верхнем углу:

```
Spawn Tracker
Без сна: 4 дн.
Фантомы: МОГУТ СПАВНИТЬСЯ
Шанс за попытку: 25%
Рядом фантомов: 2 (31m)
Свет (блок/небо): 0 / 15
Враждебных рядом: 7
Мирных рядом: 12
```

Пока порог не пройден, вместо шанса показывается «До угрозы: 12m 30s» —
сколько реального времени осталось до 72000 тиков.

Если порог пройден, но спавна нет, мод пишет **причину**: слишком светло,
вы ниже уровня моря, над вами крыша, режим наблюдателя.

## Как считается шанс

Мод повторяет логику ванильного `PhantomSpawner`. Условия, все обязательны:

| Условие | Проверка |
|---|---|
| Темнота | `getAmbientDarkness() >= 5` (ночь или гроза) |
| Высота | `y >= sea level` (обычно 64) |
| Небо | над игроком видно небо |
| Режим | не спектатор |
| Отдых | `timeSinceRest >= 72000` тиков (3 игровых дня) |

Дальше две случайные проверки, их мод переводит в проценты:

- **сложность**: `localDifficulty > random(0..3)` → шанс `difficulty / 3`
- **время без сна**: `random(x) >= 72000` → шанс `(x - 72000) / x`

Итог — произведение. На 4-й день это ~25%, на 5-й ~40%, на 6-й ~50%.
Попытка спавна происходит раз в 1–2 минуты.

## Честное ограничение

Мод **клиентский** и видит только то, что видит клиент. Отсюда два следствия:

1. **Геймрул `doInsomnia` не проверяется** — он не синхронизируется на клиент.
   Если на сервере фантомы выключены, мод всё равно покажет «могут спавниться».
2. **Счётчик мобов — не серверный mob cap.** Клиент знает только сущности в
   пределах дистанции трекинга (радиус 128 блоков в коде). Для отладки ферм и
   понимания обстановки годится, для точного расчёта капа — нет.

Я специально не стал делать серверную часть: тогда мод пришлось бы ставить и на
сервер, и он перестал бы работать на ванильных серверах.

## Управление

| Клавиша | Действие |
|---|---|
| **F6** | показать/скрыть панель |
| не назначена | показать/скрыть блок фантомов |

Переназначается в Настройки → Управление → категория «Spawn Tracker».

## Конфиг

Файл `.minecraft/config/spawntracker.properties` создаётся при первом запуске:

```properties
enabled=true
showPhantoms=true
showMobCounts=true
showLight=true
offsetX=4
offsetY=4
refreshRate=10
```

`refreshRate` — раз во сколько тиков пересчитывать данные. 10 = дважды в секунду.
Сканирование сущностей не делается каждый кадр, поэтому мод не грузит FPS.

## Сборка

Нужна **JDK 21**.

```bash
cd CreatingMods/SpawnTracker
./gradlew build
```

Готовый jar появится в `build/libs/spawntracker-1.0.0.jar`.
Файл с суффиксом `-sources` в игру класть не нужно.

Запуск тестового клиента прямо из проекта:

```bash
./gradlew runClient
```

## Установка

1. Fabric Loader для 1.21.1
2. [Fabric API](https://modrinth.com/mod/fabric-api) версии `0.116.15+1.21.1`
3. `spawntracker-1.0.0.jar` в `.minecraft/mods/`
