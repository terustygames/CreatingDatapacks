# One Block Water — сборка по шагам

Идея: сначала минимальный пак, который **точно грузится**. Потом по одной функции,
и после каждой — проверка в игре. Если что-то сломалось, виноват последний шаг.

---

## Почему был `river` на весь мир

В файле из коммита `f781e8a` все климатические параметры были обнулены:

```json
"temperature": 0, "vegetation": 0, "continents": 0, "erosion": 0, "ridges": 0
```

Биом в Overworld выбирается **только** по этим шести числам. Игра сворачивает
`ridges` (weirdness) в PV по формуле `1 - |3*|w| - 2|`. При `w = 0`:

```
PV = 1 - |0 - 2| = -1.0
```

`PV = -1.0` попадает в полосу **Valleys**, а Valleys + континентальность около нуля
= **river**. И так в каждой точке карты, потому что все шумы — константный ноль.
Отсюда один биом на весь мир.

**Починка:** вернуть настоящие шумы. Именно это стоит сейчас:

```json
"temperature": { "type": "minecraft:shifted_noise", "noise": "minecraft:temperature", ... },
"vegetation":  { "type": "minecraft:shifted_noise", "noise": "minecraft:vegetation",  ... },
"continents":  "minecraft:overworld/continents",
"erosion":     "minecraft:overworld/erosion",
"depth":       "minecraft:overworld/depth",
"ridges":      "minecraft:overworld/ridges"
```

Это ровно те же значения, что в ванильном `minecraft:overworld`. Поэтому карта биомов
получается **как в обычном мире** — плains, пустыни, océans, горы, снежные биомы.

А пустым мир делает одна строка, никак не связанная с биомами:

```json
"final_density": -1.0
```

Плотность ниже нуля = воздух везде. Рельефа нет, биомы есть. Это и требовалось.

## Что сейчас в паке (Этап 1 — минимум)

```
One block water 1.21.11/
├── pack.mcmeta
└── data/
    ├── minecraft/worldgen/world_preset/normal.json
    └── oneblockwater/worldgen/noise_settings/
        ├── empty_overworld.json
        └── empty_nether.json
```

Пять файлов. Никаких функций, тегов, структур — чтобы если оно не грузится,
причина была ровно в генерации, а не в чём-то ещё.

### Ключевые поля

| Поле | Значение | Зачем |
|---|---|---|
| `final_density` | `-1.0` | всё воздух — пустой мир |
| `sea_level` | `-64` | нет океана из воды |
| `default_fluid` | `air` | пустоты не заливаются |
| `aquifers_enabled` | `false` | без них не появятся озёра в воздухе |
| `preliminary_surface_level` | `63.0` | 2D-функция, в 1.21.9 заменила `initial_density_without_jaggedness` |
| `surface_rule` | пустая `sequence` | нечего покрывать травой |
| климат | ванильные шумы | **биомы как в обычном мире** |

## Как проверить Этап 1

1. Папку `One block water 1.21.11` — в `.minecraft/saves/<мир>/datapacks/`
   (или в `.minecraft/datapacks/` до создания мира).
2. Создать мир, тип **Normal** — пак подменяет именно этот пресет.
3. Ожидаемо: пустота во все стороны, вы падаете. Это нормально, спавн-платформы
   пока нет — её ставит функция из Этапа 2.
4. Проверить биомы: `F3` покажет **Biome** в правой колонке.
   Полетайте в креативе на пару тысяч блоков — биом должен меняться.
   Ещё быстрее: `/execute in minecraft:overworld run locate biome minecraft:desert`
   — если пустыня находится, карта биомов живая.

**Критерий успеха этапа:** мир создаётся без «Не удалось проверить набор данных»,
и в F3 встречается больше одного биома.

## Дальше по шагам

Файлы для следующих этапов лежат в `_stage2_backup/` — я их не выбрасывал.

### Этап 2 — спавн-платформа и стартовый блок
`data/minecraft/tags/function/{load,tick}.json` + `data/oneblockwater/function/*`.
Без тегов `load`/`tick` функции не запускаются вообще — это обязательная пара.

Тут же надо проверить команды на 1.21.11, в бэкапе они старые:
- `give @s fishing_rod[enchantments={mending:1}]` — синтаксис без обёртки `levels`
  правильный для 1.21.5+, но стоит проверить в игре;
- `setworldspawn` с 1.21.9 работает в любом измерении, не только в Overworld;
- в `place_portal` я добавлял запись флага `portal_placed`, иначе портал ставится
  заново при каждом входе.

## Если снова «Не удалось проверить набор данных»

Игра всегда пишет конкретную причину, но прячет её:

- в окне ошибки нажать **«Подробнее»** — там путь к файлу и что не так;
- либо в лаунчере включить вывод игры (Настройки → «Открывать вывод игры»)
  и найти строку с `ERROR`, рядом будет `Failed to load` или `Couldn't parse`.

Одна такая строка экономит час гаданий.
