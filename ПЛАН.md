## Откуда бралась ошибка `Unbound values`

```
Unbound values in registry [minecraft:worldgen/noise]
[minecraft:nether/temperature, minecraft:nether/vegetation]
```

Таких шумов в Minecraft нет. Есть `minecraft:temperature` и `minecraft:vegetation`
— **без префикса `nether/`**. Префикс `nether/` бывает только у density-функций
(`minecraft:nether/base_3d_noise`), но не у noise-параметров.

Эти ID пришли из файла, который добавила прошлая нейросеть в коммите `f781e8a`.
Я его удалял ещё в самом начале, но ошибка возвращалась — потому что в вашей папке
Minecraft оставалась старая копия пака.

**Сейчас источник устранён окончательно:** основой стала ваша рабочая версия,
в которой этих ID никогда не было.

### Отдельно: мусор в моей прошлой сборке

В `One block water 1.21.11/data/minecraft/worldgen/noise_settings/overworld.json`
затесалась случайная русская буква `в` на 19-й строке — файл был невалидным JSON.
Удалено.

## За основу взята ВАША рабочая версия

Я не стал ничего изобретать. Скопировал `One block water 1.21.11 рабочая версия`
целиком (1175 файлов) и внёс три точечные правки по вашему же списку багов.

### Баг 1 — `river` по всему миру

Было в `noise_settings/overworld.json`:

```json
"temperature": 0, "vegetation": 0, "continents": 0, "erosion": 0, "ridges": 0
```

Биом выбирается **только** по этим числам. Игра сворачивает `ridges` (weirdness)
в PV по формуле `1 - |3*|w| - 2|`. При `w = 0` выходит `PV = -1.0` — полоса
**Valleys**, а Valleys + нулевая континентальность = **river**. Везде одинаково,
потому что шум — константный ноль.

Стало:

```json
"temperature": { "type": "minecraft:shifted_noise", "noise": "minecraft:temperature", ... },
"vegetation":  { "type": "minecraft:shifted_noise", "noise": "minecraft:vegetation",  ... },
"continents":  "minecraft:overworld/continents",
"erosion":     "minecraft:overworld/erosion",
"depth":       "minecraft:overworld/depth",
"ridges":      "minecraft:overworld/ridges"
```

### Баг 2 — `nether_wastes` по всему Аду

Ровно та же причина в `noise_settings/nether.json`: `temperature` и `vegetation`
были нулями, а биом Ада выбирается именно по ним. Подключил те же ванильные шумы
— **с правильными ID, без `nether/`**.

Теперь в Аду должны встречаться crimson_forest, warped_forest, soul_sand_valley,
basalt_deltas, nether_wastes.

### Что осталось нетронутым

`"final_density": -1.0` — это и делает мир пустым. К биомам отношения не имеет,
поэтому пустота сохраняется, а биомы при этом разные.

## Про оставшиеся два бага из вашего README

### Чёрный фон в Аду

Это **не поломка пака**. Туман Ада рисуется от блоков вокруг; когда вокруг пустота,
рендерить нечего — получается чернота. Лечится только текстур-паком или модом,
датапаком не исправить.

### Одиночный блок незер-кирпича в крепости

Я проверил все 1097 `.nbt`-заглушек в паке — **внутри везде `minecraft:air`**,
то есть заглушки правильные. Блок берётся не из них.

Крепость Ада (`fortress`) генерируется кодом игры, а не шаблонами: часть её кусков
игра ставит напрямую, мимо `.nbt`. Полностью убрать её, не сломав bounding box,
нельзя — а вы писали, что ачивка за вход в fortress работает и это нужно сохранить.

Один блок на всю крепость — приемлемый компромисс. Если он мешает, можно убрать
крепость целиком через `structure_set`, но тогда пропадёт и ачивка. Скажите, если
нужно.

## Проверка

1. **Удалите старые копии пака** — иначе ошибка вернётся:
   - `%appdata%\.minecraft\saves\<мир>\datapacks\`
   - `%appdata%\.minecraft\datapacks\`

   Признак старой копии: внутри есть файл
   `data/minecraft/worldgen/noise_settings/nether.json`, где встречается
   `nether/temperature`.

2. Положите свежую папку или zip.
3. **Создайте НОВЫЙ мир**, тип **Normal**. Старый мир хранит настройки генерации
   в `level.dat` — там ошибка повторится.
4. Проверьте биомы: `F3` → строка Biome, полетать в креативе.
   Или `/locate biome minecraft:desert` — если находит, карта биомов живая.
   В Аду — `/locate biome minecraft:crimson_forest`.

Валидация перед сборкой: 71 JSON, все парсятся, все шумы и density-функции сверены
с реестрами 1.21.11, битых ID нет.
