# Trader Sound

Проигрывает звук, когда странствующий торговец появляется рядом с игроком.

Minecraft **1.21.11**, формат пака 94.1.

## Что делает

Как только в мире появляется новый странствующий торговец, всем игрокам
в радиусе **64 блоков** проигрывается его звук появления и выводится
сообщение в чат.

Звук: `minecraft:entity.wandering_trader.reappeared` — тот самый, который
играет в ваниле, когда торговец становится видимым после невидимости.

## Как устроено

Три файла:

| Файл | Роль |
|---|---|
| `data/minecraft/tags/function/tick.json` | запускает проверку каждый тик |
| `data/tradersound/function/tick.mcfunction` | ищет торговцев без тега |
| `data/tradersound/function/on_appear.mcfunction` | ставит тег и играет звук |

Ключевая деталь — **тег `ts.seen`**. Без него звук играл бы 20 раз в секунду,
пока торговец существует. Функция срабатывает только для торговцев без тега,
и первым же действием тег ставится:

```
tag @s add ts.seen
execute at @s run playsound ... @a[distance=..64] ~ ~ ~ 1.0 1.0
```

`execute at @s` важен: он делает координаты торговца точкой источника звука,
поэтому слышно, с какой стороны он появился.

## Нагрузка

Мизерная. Селектор `@e[type=wandering_trader,tag=!ts.seen]` проверяется каждый
тик, но торговцев в мире единицы, а после первого срабатывания они отсеиваются
по тегу. Ламы торговца помечаются сразу, без звука.

## Поведение в разных ситуациях

| Ситуация | Что будет |
|---|---|
| Торговец заспавнился в 30 блоках | звук + сообщение, один раз |
| Торговец заспавнился в 200 блоках | звука нет — он появился не рядом |
| Перезаход в мир | повтора нет, теги сущностей сохраняются |
| Установка пака в старый мир | у существующих торговцев звук сыграет один раз |

## Настройка

**Радиус слышимости** — в `on_appear.mcfunction` поменять `distance=..64`
в двух местах.

**Другой звук** — заменить ID в `playsound`. Варианты:
- `entity.wandering_trader.ambient` — бормотание
- `entity.wandering_trader.yes` — согласие
- `block.note_block.bell` — колокольчик, если хочется заметнее

**Убрать сообщение в чат** — удалить строку с `tellraw`.

**Громкость** — числа `1.0 1.0` в конце это громкость и высота тона.
Первое число больше 1.0 увеличивает радиус слышимости, а не громкость.

## Установка

Папку `Trader Sound` или архив `TraderSound.zip` — в
`.minecraft/saves/<мир>/datapacks/`, затем `/reload`.

Работает в существующем мире, новый создавать не нужно.

## Совместимость

Пак независим от One Block Water: свой namespace `tradersound`, общих файлов
нет. Тег `minecraft:tick` дополняет ванильный список, а не заменяет его,
поэтому оба пака работают вместе.
