# Бамбуковые доски из 4 бамбука (как в 22w42a)

Возвращает крафт, который существовал только в снапшоте **22w42a** и был убран
в **22w45a**.

## Рецепт

```
[бамбук][бамбук]
[бамбук][бамбук]   ->  2 бамбуковые доски
```

Обычный верстак, форма 2×2 (работает и в инвентаре игрока).

## Почему 2 доски, а не 4

Тут я не стал гадать. По вики 22w42a рецепт описан как
«Crafted by arranging 4 bamboo in a 2×2 pattern» — **количество на выходе там
не указано**, а сам снапшот я запустить не могу.

Поставил `count: 2`, потому что это совпадает с тем балансом, который Mojang
закрепил дальше: сейчас 1 блок бамбука (= 9 бамбука) даёт 2 доски. Вариант с
двумя досками из четырёх бамбука выглядит логичным промежуточным звеном.

**Если помните, что было 4 — поменяйте одну цифру** в файле:

```
data/bamboo22w42a/recipe/bamboo_planks_from_bamboo.json
```

строка `"count": 2` -> `"count": 4`

Готовый файл с четвёркой лежит в `ЗАПЧАСТИ-не-датапак/bamboo_planks_count4.json`
— просто скопируйте его поверх.

## Важно: ванильный рецепт остаётся

Датапак **добавляет** рецепт, а не заменяет. Крафт из блока бамбука
(1 блок -> 2 доски) продолжит работать. Оба способа будут доступны
одновременно — это нормально и ничего не ломает.

## Установка

Папка `Bamboo Planks 22w42a` или архив `BambooPlanks-22w42a.zip` — в
`.minecraft/saves/<мир>/datapacks/`.

Работает в **существующем мире**, новый создавать не нужно. После установки:

```
/reload
```

Рецепт появится в книге рецептов, как только возьмёте бамбук в руки.

## Совместимость

Этот пак **независим** от One Block Water — их можно включить вместе,
они не пересекаются ни одним файлом (разные namespace: `bamboo22w42a`
и `oneblockwater`).
