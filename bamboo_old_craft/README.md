# bamboo_old_craft

Возвращает крафт бамбуковых досок из 4 бамбука (2×2), как было в 22w42a.

```
[бамбук][бамбук]
[бамбук][бамбук]  ->  1 бамбуковая доска
```

## Что я поправил в присланной инструкции

Инструкция в целом верная, но два места на 1.21.11 не сработали бы.

### 1. `pack_format: 48` — не та версия

`48` — это 1.21.0. Для 1.21.11 нужен формат `94.1`, а с 1.21.9 поле называется
иначе. Поставил как в ваших других паках:

```json
"min_format": 88,
"max_format": 94.1
```

### 2. `"#": { "item": "minecraft:bamboo" }` — устаревший синтаксис

С **1.21.2** ингредиенты пишутся строкой, без обёртки `{"item": ...}`.
Со старым вариантом игра выдала бы в логе:

```
Failed to parse either. First: Not a string: {"item":"minecraft:bamboo"}
```

Стало:

```json
"key": { "#": "minecraft:bamboo" }
```

Остальное из инструкции — папка `data/minecraft/recipe`, `"id"` вместо `"item"`
в result, форма 2×2 — правильно.

## Важно: этот пак ЗАМЕНЯЕТ ванильный рецепт

Файл лежит по пути `data/minecraft/recipe/bamboo_planks.json` — то же имя и тот же
namespace, что у ванильного. Значит он его **перезаписывает**, а не дополняет.

Крафт «блок бамбука -> 2 доски» из-за этого пропал бы. Чтобы не терять его,
я добавил вторым файлом `bamboo_planks_from_block.json` — точную копию ванильного
рецепта под другим именем.

Итого работают **оба** способа:

| Крафт | Результат |
|---|---|
| 4 бамбука 2×2 | 1 доска |
| блок бамбука | 2 доски |

Если ванильный не нужен — просто удалите `bamboo_planks_from_block.json`.

## Количество досок

Поставил `count: 1`, как в вашей инструкции. Вики описывает форму рецепта 22w42a,
но **количество на выходе там не указано**, а сам снапшот я запустить не могу,
так что спорить не буду — ваша цифра.

Поменять просто: в `bamboo_planks.json` строка `"count": 1`.

## Установка

Папку `bamboo_old_craft` — в `.minecraft/saves/<мир>/datapacks/`.

Работает в существующем мире, потом:

```
/reload
```

## Чем отличается от `Bamboo Planks 22w42a`

Это второй, независимый пак — вы просили новую папку, старую я не трогал.

| | `bamboo_old_craft` (этот) | `Bamboo Planks 22w42a` |
|---|---|---|
| namespace | `minecraft` (заменяет) | `bamboo22w42a` (добавляет) |
| выход | 1 доска | 2 доски |
| ванильный крафт | возвращён вторым файлом | не тронут |

**Включать одновременно не стоит** — оба дают рецепт из 4 бамбука, будет дубль
в книге рецептов. Выберите один.
